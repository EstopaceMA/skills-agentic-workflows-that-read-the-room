## Recent updates worth watching (November 2026)

- **New pull request Overview page (public preview):** merge status and next actions now sit at the top of a pull request. Opt in with the "Try the Overview page" button. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview).
- **`pull_request_target` blocked by default on December 2, 2026:** Actions will block this trigger in public repositories unless an Actions event policy allows it (previously scheduled for November 2). Review any workflows that rely on it. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2).
- **Copilot in more editors:** now available in JetBrains Air and Xcode's coding assistant. Sources: [JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air), [Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant).
- **Learn Copilot agentic workflows:** [Beyond code generation: A developer's guide to agentic engineering](https://github.blog/ai-and-ml/github-copilot/beyond-code-generation-a-developers-guide-to-agentic-engineering/), [GitHub Copilot app for Beginners: teach Copilot about your codebase](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/), and [continue a Copilot app session in VS Code](https://github.blog/ai-and-ml/github-copilot/how-to-continue-a-github-copilot-app-session-in-vs-code/) (all GitHub Blog).
- **Agentic workflow examples:** browse sample workflows such as daily issues report and OSPO repo health in [Awesome Copilot](https://github.com/github/awesome-copilot/tree/main/workflows) (listed at https://awesome-copilot.github.com/workflows/).
